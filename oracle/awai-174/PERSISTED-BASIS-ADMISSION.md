# AWAI-174 persisted basis admission, hosted oracle

`kotobase.persisted-basis` composes `execute-bound!` / `execute-bound-async!` with read-only verification of a saved frontier. It checks request/manifest basis and policy, entry database and policy, the host verifier's literal-true result, and the saved frontier root and epoch. It never initializes or advances the frontier while admitting a query. The host must actually fetch and authenticate the proof, validate CID/signature/authority/checkpoint and bind it to the request's physical basis and signed manifest. A permissive verifier, malicious backend, backing-store rollback or unbounded proof fetch is not made safe by this composition.

On 2026-11-14, macOS arm64 local staged-source oracles ran JVM 3+16 and 2+11 tests/assertions for the frontier store and persisted-basis admission respectively, all passing. Compiled CLJS 1.11.132 / Node v26 exercised Promise-returning proof fetch and verifier: a valid entry admitted, false verifier rejected. Against the existing Otehon Forest stores and Ed25519 test key, `persisted_basis_forest_replay.clj` used this exact admission function with the previously saved frontier, signed proof, real fixture policy/Datalog and already-saved causal receipt. It returned the expected row and receipt with event order `[:basis :nonce :authorize :evaluate :readback]`; a modified checkpoint was rejected at `[:basis]`. No new receipt was published in this replay.

The callback and data setup in the Forest replay are fixture-owned; it does not establish a product-owned verifier, live service wiring, durable nonce ledger, anti-rollback hardware, Native or OS-reboot qualification. Its classpath and source pins follow Otehon PR #124 `README-signed-frontier-forest.md`, with this file's source copied as `.cljc` in the private staging classpath. The Kotoba bounded codec dependency remains draft PR #1339 `cc94fa4513382cbd9411ec67805dd5feccb851e2`; standard dependency resolution after the previously interrupted managed checkout has not been established.
