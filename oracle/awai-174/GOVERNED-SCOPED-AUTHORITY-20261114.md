# Issuer-scoped authority commit attestation, 2026-11-14

`authority-commit-attestation/verifier` verifies a domain-separated v1 record naming an exact authority commit CID, issuer, tenant and epoch. It resolves an unambiguous issuer key in the corresponding scoped registry, requires the configured algorithm, calls an explicit issuer-to-key authorization callback, and checks the canonical payload CID through the host crypto callback. It composes with `decision-receipt-authenticator` for exact decision-stream/basis/record readback. Registry provenance, issuer admission, current revocation state, freshness, rollback resistance, crypto implementation and backing-store durability remain host responsibilities.
