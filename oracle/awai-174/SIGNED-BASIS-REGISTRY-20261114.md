# Signed basis using the scoped key registry, 2026-11-14

`signed-basis-keys/verifier` composes the existing scoped execution-key registry with the signed-basis verifier. The host fixes the algorithm, authenticates the request tenant and epoch, decides whether the named issuer is authorized to use the registered key, and supplies signature verification. The adapter recomputes the existing domain-separated payload from root/issuer/key ID and requires literal `true` from issuer authorization and cryptography. `execution-keys/authorized-key` shares the existing duplicate-ID, role, scope and algorithm checks; it does not itself authenticate a request or verify a signature. Callbacks here are synchronous; Promise-returning callbacks are not admitted.

Local Clojure CLI 1.12.5.1654 reference runs, with the test namespaces adapted to `clojure.test` and sources copied unchanged as `.cljc`, passed 7 tests / 45 assertions across `execution-keys-test` and `signed-basis-keys-test`. The actual portable Ed25519 implementation and test-only keys also passed six signed-basis controls: valid signature, duplicated key, wrong epoch, issuer denial, altered signature and changed logical root. The first invalid operation precedes checkpoint reads in each refusal. An intentionally modified adapter that omitted issuer authorization accepted a *validly re-signed* other-issuer proof, demonstrating why the issuer gate is necessary; this was a test-only source mutation.
