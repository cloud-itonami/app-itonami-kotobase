# Authority / execution signed link reference, 2026-11-14

`kotobase.authority-execution-link/verify!` validates a versioned link against exact request, query, signed execution receipt and causal authority receipt values, recomputes their CIDs and checks action, resource, principal, tenant, query basis and epoch bindings. It requests a scoped `:authority-execution-link` executor signature verification. The host must independently authenticate the execution receipt, causal decision, issuer and trust evidence; link verification does not authenticate those sources or persist anything. Trust basis and query basis may be different.
