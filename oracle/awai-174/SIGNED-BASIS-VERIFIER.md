# AWAI-174 signed basis verification composition

On 2026-11-14 the hosted `kotobase.signed-basis/verifier` composes the existing logical commit validator, canonical domain strings, signature payload and checkpoint validator with explicit host adapters. It recomputes the logical root using the selected digest adapter; binds the physical root and policy to request and manifest; checks location; compares verified checkpoint physical root, database, epoch and logical root; and asks the host to authorize the issuer/key and verify the domain-separated signature. Every adapter must return literal true where applicable, and CLJS adapters may be asynchronous. A deployment still owns trusted key registry and crypto, digest profile, checkpoint retrieval, proof CID and location authentication. This does not define or approve a new wire format or hide those dependencies.

Local staged JVM Clojure oracle: 1 test / 12 assertions, zero failures, exercising malformed and changed physical root, policy, logical root, location, four checkpoint fields, signature and key. Compiled ClojureScript 1.11.132 / Node v26 exercised Promise-returning digest, location, checkpoint and signature adapters, including a false signature. The Forest replay in `signed_basis_forest_replay.clj` exercised the source verifier through `kotobase.persisted-basis/execute!` against the previously saved Forest proof/frontier, actual Ed25519 test key, fixture policy/Datalog and already-persisted receipt. The positive read produced `[:basis :nonce :authorize :evaluate :readback]`; changing its checkpoint was refused at `[:basis]`. No new receipt was published.

The replay uses fixture keys, clock, nonce and host-provided digest, checkpoint, location and issuer lookup. Its exact source classpaths and pins follow Otehon PR #124 `README-signed-frontier-forest.md` plus the draft Kotobase sources. It does not establish an integrated product authority, durable replay protection, Native artifact, trusted anti-rollback anchor, node failure recovery or OS cache loss. The unmerged bounded codec dependency and normal clean tools.deps resolution remain open.
