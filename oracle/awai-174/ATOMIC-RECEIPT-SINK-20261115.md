# Published receipt and nonce readback — 2026-11-15

`published-atomic-execution-receipt-sink` composes the existing canonical published receipt sink with a two-argument `(receipt, prepared-nonce)` callback. The trusted host publisher receives the validated receipt, prepared transaction and exact marker. The existing sink checks the published receipt ref and replays the exact immutable receipt from the committed branch; the new sink also reads the nonce ref and requires its CID to match before returning the acknowledgement. Malformed prepared marker shape, missing nonce ref and a different nonce CID are refused. A failure after the publisher commits can leave the nonce consumed and the receipt durable while withholding the result; it must not be retried as if no publication occurred.

The host must authenticate the scope and request, verify marker bytes and semantics, and commit an absent nonce ref with the receipt and complete closure in a single atomic transaction. Ref readback alone does not prove the host did so, provide anti-rollback or prevent a dishonest publisher. This does not introduce a Native route or silent fallback.

A one-off OpenJDK Temurin 21.0.1 hosted composition used the real request-bound governed wrapper, the real published receipt sink and Awai's streamed multi-Pack adapter. The pinned fixture supplies test keys, clock, identity and policy; it has a mostly-zero 1 GiB file. An injected publisher failure left the root unchanged, then separate allow and deny publications returned durable receipts, same-nonce replay was refused before re-evaluation, and the two WAL frames each contained group, receipt ref and nonce ref. A fresh JVM without the original source store or writer reverified both receipts, signed basis, policy and 1,024 chunks with SHA-256 `1f7e0c0d3fefe5579e556a04f7796b7de01278916e49a6d31df864e16adf1708`. Write/read took 170.18/44.42 s, max RSS 938,475,520/621,903,872 bytes; both are synthetic, warm-cache individual observations, not throughput gates.

Separate hosted controls substitute the receipt publisher to check marker forwarding, malformed shape and missing/wrong nonce refs. An additional writer-free test uses a previously published valid signed receipt and real causal receipt readback but injects a missing nonce-ref response: it was refused and root remained unchanged. Its publisher callback returns the already existing commit and performs no new write. A first invocation of that test used the wrong working directory and failed before execution; the successful run used the Awai task worktree. Neither test demonstrates actual post-commit hardware failure.
