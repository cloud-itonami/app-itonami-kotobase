# Query admission syntactic graph correction, 2026-11-14

The variable graph previously inserted edges in both directions for every clause, but used a directed-graph cycle detector. A single two-variable clause therefore always failed admission. The fanout calculation also grouped `[variable clause]` pairs by the whole pair rather than by variable. It now constructs a directed heuristic from the first distinct variable in a clause to its remaining variables, and groups distinct variable occurrences by variable. Numeric limits are unchanged. This graph is a syntactic heuristic, not a detector for Datalog rule recursion; graph cycles can describe valid finite joins. The fanout estimate does not measure or bound actual data cardinality or intermediate allocations. Production execution still requires independently enforced resource bounds.

The existing join-explosion test accidentally enclosed the subsequent star test because its closing parenthesis was misplaced; both are now independent tests. Positive one-clause, chain and bounded star queries, cyclic-query refusals, and a 32-clause fanout over 100 were checked. Changing admission permits the newly accepted bounded graph shapes; it does not authorize a new performance threshold.
