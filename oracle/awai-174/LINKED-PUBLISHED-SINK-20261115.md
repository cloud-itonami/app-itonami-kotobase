# Linked receipt publication reference, 2026-11-15

The linked governed-read option now accepts the explicit host publication transaction. It prepares the execution receipt, authority receipt and signed link in one canonical transaction, requires host semantic verification before the ref CAS, and checks the published ref and all three records after publication. The hosted pre-CAS callback checks the complete prepared record vector. Host trust, nonce persistence, ref durability and writer fencing remain explicit responsibilities; the nonce and receipt are not cross-store atomic.
