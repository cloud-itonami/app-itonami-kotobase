# Hosted request-bound nonce and atomic receipt — 2026-11-15

`kotobase.governed-atomic/execute-bound!` composes the existing synchronous governed read with a canonical nonce marker derived from that invocation's request and a host-supplied stable replay scope. It installs a read-only nonce preflight and supplies the exact prepared marker to the host's receipt publisher. It refuses an existing `:commit!` or nonce consumer instead of silently replacing them. Only one publisher call is allowed after successful preflight. The existing governed path still verifies the execution manifest, calls the supplied basis verifier, enforces policy, signs and verifies its receipt, and requires a durable acknowledgement before releasing rows.

This is a hosted Clojure composition point, not a Native runtime or independent implementation of the storage transaction. Its publisher and scope are trusted: the host must bind scope to the authenticated request, verify marker semantics, and atomically commit its absent nonce ref with the receipt and required closure. Non-reserving preflight can allow concurrent evaluations; only the publisher's conditional commit selects a winner. Rollback, external stores, distributed fencing, real authority, remote durability and production qualification remain open.

Local one-off oracle controls with OpenJDK Temurin 21.0.1 checked request-bound marker, replay refusal, nonce mismatch, publication before preflight and repeated publication refusal, async-result rejection, refusal of a preconfigured nonce consumer, and propagation of publisher failure. These controls substitute the outer governed and storage calls to isolate bridge behavior; they are not CI or Native proof.

The separate `governed_atomic_gib.clj` experiment uses the previous SHA-pinned governed GiB fixture and actual Kotobase Datalog, signed-basis/policy/receipt paths and Awai hosted atomic streamed writer. It injects a publisher failure before staging and verifies the local root is unchanged; then it publishes separate allow and deny decisions, refuses a same-nonce replay before a second evaluation, and checks both group/receipt/nonce WAL frames. Its 1,024 x 1 MiB file is mostly zero, so timings are not representative. Key material, scope, clock, authority and basis admission are fixtures; the host publisher is test composition, not a deployed product adapter. No source, runtime or cache-loss result should be inferred beyond the recorded experiment.
